# Pedro Antonio's Portfolio

A personal portfolio website built with HTML, CSS and JavaScript.

- [Abrir no navegador](file:///Users/pedrorihan/FrontEnd/meu_portifolio/index.html)

## Project Structure

- `index.html` : Main page
- `style.css` : Styles and themes
- `script.js` : Interactions and dark mode

## Getting Started

Just open the `index.html` file in your browser — no installation needed!

```bash
open index.html
```

## Features

- Light/dark mode toggle
- Animated profile photo
- Skills tags
- Certifications section
- Contact links
- Smooth scroll navigation

## Technologies Used

- HTML
- CSS
- JavaScript
- Font Awesome
- Google Fonts
